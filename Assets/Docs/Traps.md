# Existing Core Traps

1. **Poison Gas Clouds** – Time/HP tradeoff unless you find a mask.
	- Poison Spreads
	    - Ventilators in the corridor stop it
2. **Laser Barriers** – Multiple counterplays (gun, EMP, brute force).
3. **Linked Loot (Retracts on Pickup)** – Choice of one, unless you disable device.
4. **Blackouts** – Entering room drains power, limiting vision/systems.
5. **Security Cameras** – Spotted → lose time (not health).
6. **Metal Detector -** steels a random item when you cross.
7. **Keycard Steal** - opening this door steals you the keycard

Can be scaned with a thermometer. Each object can be targeted. Temperature is assigned per room. You can see the rooms temperature from the corridor, that's a way to discover hidden areas. Or maybe the thermometer checks in a sphere or cube in front of it, if multiple shows the closest one to the pointer or averages.
Room Value:
- 10: Corridor or No power
- 15: Minimal Power
- 20: Powered room
Modifiers:
- +2: Good/Electrical items
- +10: Light traps (camera, linked loot, keycard steal)
- +20: Heavy traps (Poison, Lasers, Blackout)
